从0到1创建NPM包

更新于2025-06-02|npm、JavaScript、package.json
|阅读量:

一、创建 NPM 账号并登陆

你要到 👉NPM 官网 注册一个账号。注册账号就不详细讲了，就跟你注册大多数网站的账号是一样的，然后记下自己的 用户名，密码，和 邮箱。

二、新建项目，准备需要发布的代码

三、配置包的参数

进入目标文件夹终端运行 npm init ，根据提示输入内容

输入完成后，会给我们一个预览，问我们这样可以吗，然后我们回车即可。来看看都有哪些内容

  • package name： 括号里面这个就是替你默认把文件夹名放在这里了，直接使用就行，也可以改成其他的。这是我们后面用于下载时候的包名。

  • version： 版本号。括号里默认是 1.0.0 ，并且需要遵循 x.x.x 的格式。

  • description： 编写描述信息，有助于人们在 npm 库中搜索的时候发现你的模块。

  • entry point： 指定了加载的入口文件，默认是 index.js。

  • test command： 测试指令，本文用不到，可以不填。

  • git repository： 指定一个代码存放地址，本文用不到，可以不填。

  • keywords： 关键字，有助于人们在 npm 库中搜索的时候发现你的模块。

  • author： 作者的名字。

  • license： 当前项目的协议，让用户知道他们有何权限来使用你的模块，默认是 ISC。

之后会在根目录下生成一个 package.json 的文件。内容就是我们刚刚配置的那些。

四、开始发包

确认 npm 的所用源

如果不是的话，需要设置成 npm 官网的源

登录自己的 npm 账号

根据提示填自己官网注册的信息即可。

发布包

这一句将会把你现在的程序包发布到 npm 官网上，而且是公有的包，任何一个用户都可以使用

发现图中报了 403 的错误，这是因为我们的包名已经被别人使用了，所以我们需要修改一下。

修改完以后再次运行 npm publish –access public ，当我们看到 +xxx 就证明我们已经发布成功了。现在去 npm 的官网看一下。

可以看到我们的代码就成功的被发布到 npm 上了。
